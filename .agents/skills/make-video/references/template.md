# 模板风格与能力

本模板由一次 60 秒科技解说动效工程整理而来。风格参考是随包的自有工程渲染：assets/reference/storyboard.jpg 与九张场景 JPG，三种全尺寸封面及 sfx-style.wav。索引在 assets/reference/index.json；不携带原片画面、原配音或源视频。

## 固定镜头语言

深色背景、冷紫强调、金色数据对比；少量粒子、颗粒、辉光和金属反射。主体通过四边形投影形成透视，摄像机运动由轨迹控制。文字先搭骨架后揭示，关键数值滚动并落定；声音按扫描、定位、飞掠、计数和结构展开等事件编排。

场景库：芯片透视与租金/产出对比 → 百分比数据墙 → 日期/系统立方体 → 五层结构 → 双章节与成本图 → 仪表命题与否定划线 → 主题标题 → 空间新闻卡片 → 参数矩阵/分词/代码。还可加入真实图片/视频 media 场景。数组可删减、重排、复制，不强制固定九镜顺序。

## 本期替换映射

| 要替换的内容 | 实际入口 |
| --- | --- |
| 本期文案、指标、结构标注、新闻、代码 | work/project/content.json 的 scenes[].data |
| 镜头顺序、时长、横竖屏 | scenes 数组、duration、video.aspect |
| 竖屏主题与说明 | scenes[].title / summary |
| 主题色 | theme；材质细节仍有固定颜色 |
| 图片/视频 | media 场景，文件实际放 public/ |
| 字幕 | subtitles 的秒级 start/end/text |
| 程序音效 | audio.sfx；src/cue-presets.json 可细调提示点 |
| 配音/额外音效 | audio.voiceover / cues，真实本地文件 |
| 封面文案与选景 | cover.title/subtitle/eyebrow/sceneId/progress |

真实参数 schema 在 src/content.ts，命令和单位见 remotion.md。更换主题需要重写镜头内容及核实事实；默认虚构 Aster 仅展示排版与数据。改变主体造型、复杂仿真或特定产品外观需新增组件或素材。表面贴图不是任意新主体的万能接口。
